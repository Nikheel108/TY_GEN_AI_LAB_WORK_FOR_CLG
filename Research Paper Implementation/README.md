## Paper
D. P. Kingma and M. Welling, *Auto-Encoding Variational Bayes*, ICLR 2014.
- Abstract: https://arxiv.org/abs/1312.6114
- PDF: https://arxiv.org/pdf/1312.6114

## What this project does
Implements the core methodology of the paper from scratch in PyTorch and trains it on MNIST:
- Gaussian encoder q(z|x), reparameterization trick (z = mu + sigma * eps), Bernoulli decoder p(x|z)
- Negative ELBO loss = binary cross-entropy + closed-form KL divergence
- Reconstructions, samples from the prior, latent interpolation
- 2-D latent manifold visualisation (Fig. 4 of the paper)
- Result analysis: latent-size ablation, active latent units, VAE vs plain autoencoder, linear classification on latent codes
- Improvement experiment: convolutional VAE
- Limitations and suggested improvements

## How to run (Google Colab)
1. Open https://colab.research.google.com and choose **File -> Upload notebook**, then select `VAE_Implementation.ipynb`.
2. (Optional) **Runtime -> Change runtime type -> GPU**. The models are small, so CPU also works.
3. Click **Runtime -> Run all**. The notebook downloads MNIST automatically (GitHub mirror, with a torchvision fallback), so no manual dataset setup is needed.
4. Figures are saved to `figs/` and metrics to `results.json` inside the Colab session.

**Requirements:** Python 3, PyTorch, NumPy, Matplotlib, scikit-learn (all preinstalled in Colab).
**Runtime:** about 15-20 minutes on CPU, a few minutes on a GPU.

## Setup used
- Dataset: MNIST, 60,000 train / 10,000 test, pixels scaled to [0, 1]
- Model: MLP, 784 -> 500 (tanh) -> latent z (20) -> 500 (tanh) -> 784; 815,824 parameters
- Optimiser: Adam, lr 1e-3, batch size 128, 30 epochs (main model), seed 42

## Key results (from the run used for the report; Colab numbers may differ slightly)
| Experiment | Test -ELBO (nats/image) |
|---|---|
| MLP-VAE, z = 20 (30 epochs) | 102.75 |
| MLP-VAE, z = 2 (30 epochs) | 148.82 |
| Conv-VAE, z = 20 (15 epochs) | 100.48 |

- Latent size: bound improves up to z = 20 and does not improve at z = 50 (only 32 of 50 units active).
- Plain autoencoder reconstructs better (BCE 66.3 vs 77.8) but cannot generate usable samples from N(0, I).
- Linear classifier on 20-D latent codes: 89.1% test accuracy.
